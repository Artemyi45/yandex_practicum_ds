# Обучение с учителем: качество модели

## Задача
Разработать модель для предсказания снижения покупательской активности. Выделить сегменты клиентов и предложить персонализированные стратегии удержания.

## Данные
- `market_file.csv` — 1 300 клиентов: активность, сервис, маркетинг, просмотры, корзина, ошибки.
- `market_money.csv` — выручка по периодам.
- `market_time.csv` — время на сайте по периодам.
- `money.csv` — среднемесячная прибыль с клиента.

## Ход работы
1. **Загрузка и предобработка** — snake_case, lower case, LabelEncoder, pivot таблиц.
2. **EDA** — статистика, распределения, анализ выручки по периодам.
3. **Объединение таблиц** — pivot по периодам, merge по id.
4. **Корреляционный анализ** — phik-матрица.
5. **Пайплайны и модели** — ColumnTransformer, StandardScaler, RobustScaler, OrdinalEncoder, OneHotEncoder. LogisticRegression, DecisionTree. RandomizedSearchCV.
6. **Важность признаков** — Permutation Importance.
7. **Сегментация** — KMeans (4 кластера), анализ каждого кластера, стратегии удержания.

## Результаты
- Лучшая модель: LogisticRegression, ROC-AUC = 0.88 (CV), 0.87 (test).
- Топ-признаки: согласие на коммуникацию, товары в корзине, время на сайте, акционные покупки, выручка.
- 4 кластера клиентов. Кластер 2 (13% клиентов, 80% оттока) — критическая группа.
- Разработаны персонализированные стратегии и roadmap на 6 месяцев.
