# Прогнозирование температуры стали

## Задача
Построить модель для предсказания конечной температуры сплава на металлургическом комбинате «Стальная птица». Порог заказчика: MAE < 6.8°C.

## Данные
База данных SQLite из 7 таблиц (~50 000 записей):
- `data_arc` — электроды (мощность, длительность нагрева).
- `data_bulk` — сыпучие материалы (объём, время подачи).
- `data_gas` — продувка газом.
- `data_temp` — измерения температуры.
- `data_wire` — проволочные материалы (объём, время подачи).

## Ход работы
1. **EDA и предобработка** — удаление аномалий (партия с реактивной мощностью –715, замеры <1500°), заполнение пропусков, генерация признаков.
2. **Feature Engineering** — длительность нагрева, полная мощность, соотношение мощностей, количество подач, размах времени.
3. **Корреляционный анализ** — корреляция Спирмена, мультиколлинеарность. Исключены признаки с утечкой (средняя температура, размах температуры).
4. **Модели** — DecisionTree, RandomForest, GradientBoosting, XGBoost, нейронная сеть (Keras). GridSearchCV.
5. **Оценка** — GradientBoosting показал лучший результат.

## Результаты

| Модель | MAE (CV), °C |
|:---|---:|
| GradientBoosting (tuned) | 6.66 |
| RandomForest (tuned) | 6.71 |
| XGBoost | 6.94 |
| DecisionTree | 9.31 |
| Нейронная сеть (Keras) | 29.67 |

**Финальный MAE на тесте: 6.62°C** (порог 6.8°C пройден).

## Бизнес-выводы
- Главный управляющий фактор — начальная температура (22% важности).
- Увеличение времени нагрева на 500 сек повышает температуру на ~4°C.
- Модель готова к имитационному моделированию.
