# HR-аналитика: удовлетворённость и увольнение

## Задача
Разработать модель для предсказания уровня удовлетворённости сотрудника и вероятности его увольнения.

## Данные
- `train_job_satisfaction_rate.csv` — 4 000 сотрудников с целевым признаком (удовлетворённость).
- `train_quit.csv` — 4 000 сотрудников с целевым признаком (увольнение).
- `test_features.csv` — 2 000 сотрудников без целевых признаков.
- `test_target_*.csv` — целевые признаки для тестовой выборки.

## Ход работы

### Задача 1: Предсказание удовлетворённости (регрессия)
1. **Загрузка и предобработка** — пропуски, дубликаты, типы данных.
2. **EDA** — распределения, корреляции (phik), scatterplot-ы.
3. **Пайплайн** — ColumnTransformer: OHE, OrdinalEncoder, StandardScaler.
4. **Модели** — LinearRegression, DecisionTree, RandomForest. Подбор гиперпараметров.
5. **Оценка** — SMAPE. Лучшая: RandomForest (13.86% CV, 12.81% test).

### Задача 2: Предсказание увольнения (классификация)
6. **EDA** — портрет уволившегося сотрудника, распределения.
7. **Feature Engineering** — добавление предсказанной удовлетворённости как нового признака.
8. **Пайплайн и модели** — LogisticRegression, SVM, KNN, DT, RF. GridSearchCV.
9. **Оценка** — ROC-AUC. Лучшая: RandomForest (0.937 CV, 0.929 test).

## Результаты

### Задача 1
- Лучшая модель: RandomForestRegressor.
- SMAPE: 12.81% (порог ≤ 15%).
- Топ-признаки: оценка руководителя, зарплата, нарушения, стаж.

### Задача 2
- Лучшая модель: RandomForestClassifier.
- ROC-AUC: 0.929 (порог ≥ 0.91).
- Топ-признаки: удовлетворённость, уровень должности, стаж, зарплата.
- Портрет уволившегося: junior, низкая зарплата, низкая удовлетворённость, нет повышения.
