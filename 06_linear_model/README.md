# Линейные модели: Экоферма

## Задача
Разработать модель для прогноза удоя коров и вероятности получения вкусного молока. Помочь фермеру выбрать коров для покупки с минимальным риском.

## Данные
- `ferma_main.csv` — 629 коров: удой, характеристики корма, порода, пастбище, жирность, белок, вкус молока, возраст.
- `ferma_dad.csv` — имена пап коров.
- `cow_buy.csv` — 20 коров на продажу (без удоя и вкуса молока).

## Ход работы
1. **Загрузка и предобработка** — переименование столбцов, удаление дубликатов, приведение типов, замена аномалий.
2. **EDA** — статистический анализ, графики распределений, выбросы.
3. **Корреляционный анализ** — phik-матрица, scatterplot-ы, VIF-анализ мультиколлинеарности.
4. **Линейная регрессия (3 модели):**
   - Базовая модель (R² = 0.832).
   - С бинарным СПО и Energy² (R² = 0.844).
   - С данными об отце (R² = 0.861).
5. **Логистическая регрессия** — прогноз вкуса молока. Подбор порога для минимизации ошибки I рода.
6. **Прогноз для новых коров** — отбор 4 коров с удоем > 6 000 кг и вкусным молоком.

## Результаты
- Лучшая регрессионная модель — R² = 0.861, RMSE = 195 кг.
- Логистическая регрессия: Accuracy = 63%, Recall = 75% (после подбора порога Precision = 100%).
- Рекомендовано купить 4 коров с ожидаемым удоем 6 000–6 500 кг/год и вкусным молоком.
