# Поиск по изображениям (With Sense)

## Задача
Создать модель, которая по текстовому запросу пользователя выводит релевантное изображение. Прототип для видеохостинга «With Sense».

## Данные
- `train_dataset.csv` — 5 822 пары изображение-описание.
- `train_images/` — изображения для обучения.
- `CrowdAnnotations.tsv` — оценки краудсорсинга.
- `ExpertAnnotations.tsv` — оценки трёх экспертов (шкала 1–4).
- `test_queries.csv` — 500 тестовых запросов.
- `test_images/` — 100 изображений для тестирования.

## Ход работы
1. **EDA и сбор таргета** — объединение оценок экспертов (60%) и краудсорсинга (40%). Удаление изображений с детьми (legal compliance). Финальный датасет: 514 строк.
2. **Векторизация** — изображения через ResNet-18 (25 088 признаков), тексты через TF-IDF (455 признаков).
3. **Two-Tower архитектура** — TruncatedSVD (128 компонент) для снижения размерности изображений, LinearRegression для проекции текста в то же пространство.
4. **Поиск** — Cosine Similarity между вектором текста и векторами изображений.
5. **Демонстрация** — на 10 тестовых запросах модель подбирает разные изображения, улавливает смысловые концепты.

## Результаты

| Модель | MAE (test) | RMSE (test) |
|:---|---:|---:|
| Ridge | 0.236 | 0.302 |
| PyTorch NN | 0.240 | 0.293 |

Прототип работает: разные запросы → разные изображения, без «популярного соседа».

## Бизнес-выводы
- Для продакшена рекомендуется заменить TF-IDF на CLIP или аналогичную мультимодальную модель.
- Система готова к пилотному запуску.
