# Исследование российского кинопроката

## 🎯 Задача
Провести анализ рынка российского кинопроката, изучить текущие тренды и оценить эффективность государственной поддержки фильмов.

## 📊 Данные
- `mkrf_movies.csv` — 7 485 фильмов с характеристиками (бюджет, сборы, жанр, режиссёр, возрастное ограничение).
- `mkrf_shows.csv` — данные о прокате фильмов.

## 🧠 Ход работы
1. **Загрузка и объединение** — слияние двух таблиц по номеру прокатного удостоверения.
2. **Предобработка** — типы данных, пропуски, дубликаты, неявные повторы, категориальные и количественные аномалии.
3. **Feature Engineering** — год проката, главный режиссёр, основной жанр, доля господдержки.
4. **EDA** — динамика проката по годам, влияние возрастных ограничений на сборы, средние и медианные сборы.
5. **Анализ господдержки** — окупаемость, рейтинги, объёмы финансирования по годам.

## 📈 Результаты
- Количество фильмов и сборы растут с 2010 по 2019 год.
- Самые кассовые категории: 16+, 12+, 6+.
- Фильмы с господдержкой собирают в 4.5 раза больше, но имеют чуть более низкий рейтинг.
- Господдержка покрывает в среднем 55% бюджета фильма.
