# Выбор локации для скважины

## Задача
Определить наиболее перспективный регион для бурения нефтяных скважин. Выбрать регион с максимальной средней прибылью при допустимом риске убытков менее 2.5%.

## Данные
- `geo_data_0.csv`, `geo_data_1.csv`, `geo_data_2.csv` — данные геологоразведки трёх регионов (по 100 000 точек).
- Признаки: `f0`, `f1`, `f2` (анонимизированные), `product` — объём запасов (тыс. баррелей).

## Ход работы
1. **Загрузка и EDA** — пропуски, дубликаты, типы, статистика, корреляции, scatterplot-ы.
2. **Моделирование** — LinearRegression для каждого региона. Оценка R², MAE, RMSE.
3. **Расчёт прибыли** — функция `calculate_profit`: выбор 200 лучших скважин по предсказанию, суммирование фактических запасов.
4. **Bootstrap-анализ** — 1 000 итераций, распределение прибыли, доверительный интервал 95%, вероятность убытков.

## 📈 Результаты

| Регион | R² | MAE | Средняя прибыль | Риск убытков |
|:---|---:|---:|---:|---:|
| 0 | 0.27 | 31.0 | 0.40 млрд | 5.20% |
| **1** | **1.00** | **0.7** | **0.44 млрд** | **1.90%** |
| 2 | 0.20 | 32.9 | 0.39 млрд | 8.80% |

**Выбран Регион 1** — единственный с риском убытков ниже 2.5% и максимальной средней прибылью.
