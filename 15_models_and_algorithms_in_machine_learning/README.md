# Прогнозирование температуры звезды

## Задача
С помощью нейросети определять температуру на поверхности обнаруженных звёзд. Задача от обсерватории «Небо на ладони». Порог заказчика: RMSE < 4500 K.

## Данные
- `6_class.csv` — данные из учебной платформы Яндекс.Практикума (240 звёзд, 7 признаков).
- Признаки: светимость (L/Lo), радиус (R/Ro), абсолютная звёздная величина, цвет, тип звезды.
- Целевая переменная: температура (K).

## Ход работы
1. **Загрузка и предобработка** — удаление служебного столбца, объединение категорий цвета.
2. **EDA** — распределения, log-scale scatterplot-ы, корреляционная матрица.
3. **Подготовка данных** — OneHotEncoder для цвета и типа звезды, StandardScaler для числовых признаков.
4. **Baseline-модель** — полносвязная сеть (3 слоя, ReLU, Adam, MSE). RMSE = 8 698 K.
5. **Улучшение** — перебор dropout (0.0–0.5) и batch_size (16–64) через кросс-валидацию 5 фолдов. Лучшая комбинация: dropout=0.0, batch_size=16.
6. **Финальная модель** — RMSE = 3 945 K на тесте.

## Результаты

|:---|---:|
