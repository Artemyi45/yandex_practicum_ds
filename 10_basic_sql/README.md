# SQL: Анализ венчурных фондов и инвестиций

## Задача
Проанализировать данные о венчурных фондах и инвестициях в стартапы. Написать серию SQL-запросов к базе данных.

## Данные
База данных из 7 таблиц: `company`, `fund`, `funding_round`, `investment`, `acquisition`, `people`, `education`.

## Что отработано
- Простые SELECT-запросы с фильтрацией (`WHERE`, `LIKE`, `BETWEEN`).
- Агрегация и группировка (`GROUP BY`, `HAVING`, `SUM`, `AVG`, `COUNT`).
- JOIN-ы (`INNER JOIN`, `LEFT JOIN`).
- Подзапросы и вложенные конструкции.
- CASE-операторы для категоризации.
- Pivot-таблицы через `CASE` + `GROUP BY`.
- Оконные функции.
