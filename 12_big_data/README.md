# Предсказание цен на жилую недвижимость (Spark)

## Задача
Обучить модель линейной регрессии на данных о жилье в Калифорнии (1990 год) с использованием PySpark.

## Данные
- `housing.csv` — 20 640 записей, 10 признаков.
- Признаки: координаты, возраст жилья, комнаты, спальни, население, домохозяйства, доход, близость к океану.
- Целевая переменная: `median_house_value`.

## Ход работы
1. **Инициализация Spark-сессии** — локальный запуск PySpark.
2. **Загрузка и EDA** — схема данных, пропуски, статистика, распределение категорий.
3. **Предобработка** — заполнение пропусков медианой, StringIndexer + OneHotEncoder для `ocean_proximity`.
4. **Feature Engineering** — VectorAssembler для числовых и всех признаков.
5. **Модели** — две версии LinearRegression (только числовые vs все признаки).
6. **Оценка** — RMSE, MAE, R² на тестовой выборке.

## Результаты

| Модель | RMSE | MAE | R² |
|:---|---:|---:|---:|
| Только числовые признаки | 71 792 | 51 805 | 0.6275 |
| Все признаки (+ OHE) | 70 787 | 50 864 | 0.6378 |

Добавление категориального признака `ocean_proximity` улучшило все метрики.
