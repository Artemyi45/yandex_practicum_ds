# Классификация токсичных комментариев

## Задача
Обучить модель классифицировать комментарии на позитивные и негативные для автоматической модерации. Порог заказчика: F1 ≥ 0.75.

## Данные
- `toxic_comments.csv` — 159 292 комментария.
- Признаки: `text` (текст комментария), `toxic` (целевой признак: 0/1).
- Дисбаланс классов: 10% токсичных.

## Ход работы
1. **Загрузка и EDA** — баланс классов, пропуски, дубликаты.
2. **Предобработка** — очистка текста (lowercase, удаление спецсимволов).
3. **Разделение** — train/val/test (70/15/15), стратификация.
4. **Векторизация** — TF-IDF, ngram_range=(1,2), max_features=10000.
5. **Модели** — LogisticRegression, RandomForest. GridSearchCV.
6. **Оценка** — F1-score.

## Результаты

| Модель | F1 (val) | F1 (test) |
|:---|---:|---:|
| LogisticRegression (baseline) | 0.704 | — |
| LogisticRegression (tuned) | 0.748 | **0.752** |
| RandomForest (tuned) | 0.621 | — |

Порог F1 ≥ 0.75 достигнут на тестовой выборке.
