# Яндекс Музыка: сравнение Москвы и Петербурга

## Задача
Проверить три гипотезы о поведении пользователей Яндекс Музыки в Москве и Санкт-Петербурге.

## Данные
- Файл `yandex_music_project.csv` (65 079 строк, 7 столбцов).
- Данные о треках, жанрах, времени и городе прослушивания.

## Ход работы
1. **Обзор данных** — пропуски, дубликаты, аномалии в жанрах.
2. **Предобработка** — переименование столбцов, заполнение пропусков, удаление дубликатов, объединение жанров.
3. **Проверка гипотез** — анализ активности по дням недели, жанровых предпочтений утром и вечером, сравнение топ-жанров двух столиц.

## Результаты
- Активность пользователей зависит от дня недели — гипотеза подтверждена.
- Жанровые предпочтения утром и вечером различаются слабо — гипотеза подтверждена частично.
- Москва и Петербург предпочитают похожую музыку — гипотеза о различии жанров не подтверждена.

## Стек
Python, Pandas

## Запуск
Открыть `yandex_music.ipynb` в Jupyter Notebook.
