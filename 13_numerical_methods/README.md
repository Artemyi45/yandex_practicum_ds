# Определение стоимости автомобиля

## Задача
Построить модель машинного обучения для предсказания рыночной стоимости автомобиля с пробегом. Критерий заказчика: RMSE < 2500.

## Данные
- `autos.csv` — 354 369 объявлений о продаже авто.
- Признаки: тип кузова, год регистрации, коробка передач, мощность, модель, пробег, тип топлива, марка, ремонт.

## Ход работы
1. **Загрузка и предобработка** — удаление дубликатов, неинформативных признаков, обработка аномалий (год, мощность, цена), заполнение пропусков с флагами.
2. **EDA** — распределения, корреляционная матрица (phik). Сильнее всего с ценой коррелируют: год регистрации, мощность, модель.
3. **Пайплайн** — ColumnTransformer: OneHotEncoder для категорий, StandardScaler для числовых.
4. **Модели** — Ridge, RandomForest, LightGBM, CatBoost. Сравнение по RMSE, времени обучения, времени предсказания.
5. **Настройка** — GridSearchCV для LightGBM.
6. **Финальная оценка** — тестовая выборка.

## Результаты

| Модель | RMSE (val) | Время обучения |
|:---|---:|---:|
| Ridge | 2 517 | 3 сек |
| RandomForest | 1 575 | 42 сек |
| CatBoost | 1 586 | 23 сек |
| **LightGBM (tuned)** | **1 615** | **6 сек** |

**Финальный RMSE на тесте: 1 617** (порог 2 500 пройден).
