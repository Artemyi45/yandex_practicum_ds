# Определение возраста покупателей (Computer Vision)

## Задача
Построить модель, которая по фотографии определяет приблизительный возраст человека. Порог заказчика: MAE < 8 лет.

## Данные
- `labels.csv` — 7 591 фотография с указанием реального возраста.
- Изображения из папки `final_files/`.
- Данные взяты с ChaLearn Looking at People.

## Ход работы
1. **EDA** — распределение возраста (1–100 лет, средний 31 год), визуальный осмотр фото.
2. **Подготовка данных** — ImageDataGenerator, rescale, horizontal_flip, train/val split 75/25.
3. **Модель** — ResNet50 (предобученная на ImageNet), GlobalAveragePooling2D, Dense(1), Adam (lr=0.0001), MSE.
4. **Обучение** — 10 эпох, batch_size=32.

## Результаты

| Эпоха | MAE (train) | MAE (val) |
|:---|---:|---:|
| 10 | 2.57 | **5.82** |

Порог MAE < 8 пройден. Модель ошибается в среднем на 5.8 лет.

## Бизнес-выводы
- Для анализа покупок и рекомендаций — модель готова к внедрению.
- Для контроля продажи алкоголя — использовать как вспомогательную систему, окончательное решение за кассиром.
