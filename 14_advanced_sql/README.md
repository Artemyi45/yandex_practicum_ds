# SQL: Анализ данных StackOverflow

## Задача
Проанализировать данные сервиса вопросов и ответов о программировании StackOverflow. Написать серию SQL-запросов к базе данных.

## Данные
База данных из 6 таблиц:
- `badges` — значки за достижения.
- `post_types` — типы постов (вопрос/ответ).
- `posts` — посты (заголовок, дата, очки, просмотры).
- `users` — пользователи (имя, репутация, просмотры профиля).
- `vote_types` — типы голосов (UpMod, DownMod, Close и др.).
- `votes` — голоса за посты.

## Что отработано

### Часть 1 (12 задач)
- Агрегация и фильтрация (`WHERE`, `HAVING`, `COUNT`, `AVG`, `SUM`).
- Работа с датами (`BETWEEN`, `DATE_TRUNC`, извлечение дня/месяца/года).
- Подзапросы и CTE.
- Оконные функции (`ROW_NUMBER`, `RANK`, `SUM() OVER`).
- JOIN-ы между таблицами.
- Группировка с условиями.

### Часть 2 (7 задач)
- Скользящие суммы и накопление (`SUM() OVER`, `ORDER BY`).
- Ранжирование и лидеры групп (`RANK`, `MAX`).
- Интервалы между датами (`INTERVAL`, разница между регистрацией и первым постом).
- Месячная динамика (прирост в процентах, сравнение с предыдущим периодом).
- Агрегация по неделям и дням.
- Поиск самого активного пользователя.
