# Оценка риска ДТП для каршеринга

## Задача
Разработать модель для оценки риска ДТП (виновности водителя) на основе исторических данных каршеринговой компании.

## Данные
Облачная база данных PostgreSQL из 3 таблиц:
- `collisions` — информация о ДТП (дата, погода, дорога, освещение).
- `parties` — участники ДТП (виновность, опьянение, страховка).
- `vehicles` — автомобили (тип, возраст, КПП).

## Ход работы
1. **Загрузка SQL** — подключение к облачной БД, фильтрация за 2012 год.
2. **EDA** — сезонность, распределения, связь признаков с виновностью.
3. **Предобработка** — заполнение пропусков, OneHotEncoder, StandardScaler.
4. **Модели** — LogisticRegression, RandomForest, CatBoost. RandomizedSearchCV.
5. **Оценка** — CatBoost (F1=0.63, ROC-AUC=0.68).
6. **Важность признаков** — ключевые факторы: страховка, тип авто, час, возраст авто.

## Результаты

| Модель | F1 (CV) |
|:---|---:|
| LogisticRegression | 0.582 |
| RandomForest | 0.612 |
| **CatBoost** | **0.613** |

**Финальный F1 на тесте: 0.629.**
