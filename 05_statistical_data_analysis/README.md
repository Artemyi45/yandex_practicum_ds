# Анализ сервиса Go

## Задача
Проанализировать данные сервиса проката самокатов и проверить гипотезы: влияет ли подписка Ultra на длительность поездок, расстояние и помесячную выручку.

## Данные
- `users_go.csv` — 1 565 пользователей (возраст, город, тип подписки).
- `rides_go.csv` — 18 068 поездок (расстояние, длительность, дата).
- `subscriptions_go.csv` — тарифы (free и ultra).

## Ход работы
1. **Загрузка и предобработка** — дубликаты, типы данных, новый столбец с месяцем.
2. **EDA** — распределение городов, возраст, подписки, расстояние и длительность поездок.
3. **Объединение данных** — слияние трёх таблиц в один датафрейм.
4. **Подсчёт выручки** — агрегация по пользователю и месяцу, расчёт помесячной выручки.
5. **Проверка гипотез** — статистические тесты (Манна-Уитни, Уилкоксона).

## Результаты
- Подписка Ultra увеличивает среднюю выручку на 10.9% (361.5 ₽ vs 325.8 ₽).
- Длительность поездок у Ultra выше всего на 1.1 мин — статистически значимо, но несущественно.
- Среднее расстояние у Ultra (3 115 м) не превышает оптимальное (3 130 м), но 51.5% поездок — превышают.
- Данных об обращениях в техподдержку нет — гипотезу проверить не удалось.

## Стек
Python, Pandas, Matplotlib, Seaborn, NumPy, SciPy
